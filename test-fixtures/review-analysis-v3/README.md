# Review analysis v3 test set

The synthetic core of the evaluation set for review analysis v3 (contract section 8,
decisions 5 and 6 of `v3-contract-decisions.md`). Every review here is invented: invented
names, places and businesses, written by two model families to a quota
(`testset-quota.md`), then labelled by both families under the annotation guide v3 with its
clarifications v3.1 and v3.2. No real guest review, and no text from a real business, belongs in
this folder. The live slice that measures the beta organizations' own reviews is a separate table
keyed by review ID that holds no text (ADR 0031, amendment "Guest voice 2.0").

| File                 | What it holds                                                          |
| -------------------- | ---------------------------------------------------------------------- |
| `items-codex.jsonl`  | 200 reviews generated by Codex (`cx-0001` to `cx-0200`)                |
| `items-claude.jsonl` | 200 reviews generated by Claude (`cl-0001` to `cl-0200`)               |
| `gold-v1.jsonl`      | the settled labels of 395 of the 400 reviews, in the v3 answer's shape |

An item is `{ id, business, rating, language, text, sentences, tags }`. `business` is a Google
primary category, `language` is `en`, `bg`, `es`, `de` or `mixed`, `sentences` is the text cut by
the production splitter (`src/shared/review-sentences.ts`), and `tags` record what the item was
written to test (urgent cases, near misses, names, sarcasm, rating conflicts, content-free
text). A gold label is `{ id, sentiment, mentions, urgent, gold_source }`; `gold_source` says
which round settled it.

Five items have no gold label yet: `cl-0021`, `cl-0054`, `cl-0163`, `cl-0174` and `cl-0188`. The
two families still disagreed after three rounds and the owner settles them. The harness leaves
them out of every score and names them in its report.

All 30 urgent cases are in English (11 safety, 9 health, 4 discrimination, 6 legal threat). The
Urgent recall of Bulgarian and Spanish cannot be measured on this set; the harness says so
instead of passing it.

Run the harness with `pnpm eval:review-analysis-v3` (see `scripts/evaluation/`). It never calls
a provider in tests or CI.
